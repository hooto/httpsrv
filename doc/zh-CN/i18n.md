# i18n 国际化

i18n 在 v2 中是一个**显式开启的模块，默认不加载**。需要时通过 `WithI18n` 挂到 App、并把模板函数 `i.Funcs()` 传给 `Renderer`。语言匹配用标准库 `golang.org/x/text`（BCP-47）。

消息结构是最简形式 `locale → key → text`（**不区分单数/复数**）；本模块不含日期/数字/货币/时区格式化。

## 总览

| 能力 | 入口 |
|---|---|
| locale 探测 | `app.Use(AcceptLanguage("en", "zh", ...))` 中间件 |
| Handler 内取 locale | `c.Locale()` |
| Handler 内翻译 | `c.Translate(locale, key, args...)` |
| 消息存储 | `I18n`（`NewI18n` / `Add` / `Set` / `LoadJSON`） |
| 模板内翻译 | `T`（由 `i.Funcs()` 注入） |

## 1. Accept-Language 中间件

```go
app := httpsrv.New()
app.Use(httpsrv.AcceptLanguage("en", "zh", "ja")) // 首个为默认/兜底
```

- 解析请求头 `Accept-Language`，按 BCP-47 匹配到支持的 locale（如 `en-US` → `en`，`zh-Hans` → `zh`）。
- 匹配不到时回退到第一个参数（默认）。
- 结果写入 request context，`c.Locale()` 读取。

## 2. 消息存储 I18n（扁平 key → text）

```go
i := httpsrv.NewI18n("en") // 默认语言

// 批量
i.Add("zh", map[string]string{"welcome": "欢迎", "hi": "你好 %s"})
i.Add("en", map[string]string{"welcome": "Welcome", "hi": "Hi %s"})

// 单条
i.Set("en", "bye", "Bye")

// 从 JSON 加载（扁平 {"key": "text"}）
i.LoadJSON("en", []byte(`{"welcome": "Welcome", "hi": "Hi %s"}`))
```

翻译：
```go
i.Translate("en", "welcome")      // "Welcome"
i.Translate("zh", "missing")      // 回退默认语言 → 再回退 key："missing"
i.Translate("zh", "hi", "Alice")  // "你好 Alice"（args 走 fmt.Sprintf）
```

- 查找链：请求 locale → 默认 locale → key 本身。
- locale 大小写不敏感。

## 3. 挂到 App（Handler 内使用）

```go
app := httpsrv.New(httpsrv.WithI18n(i))

app.Get("/", func(c httpsrv.Ctx) error {
    return c.SendString(c.Translate(c.Locale(), "welcome"))
})
```

- 未挂 `WithI18n` 时：`c.Translate(...)` 直接返回 key（i18n 模块未加载）。
- 未用 `AcceptLanguage` 中间件时：`c.Locale()` 回退到 i18n 默认语言，再回退空串。

## 4. 模板内使用（T）

把 `i.Funcs()` 作为额外模板函数传给 `Renderer`：

```go
r, _ := httpsrv.TemplatesFS(views, i.Funcs())
app := httpsrv.New(httpsrv.WithViews(r), httpsrv.WithI18n(i))
```

模板：`<h1>{{T .Lang "welcome"}}</h1>`

## 完整示例

```go
package main

import (
	"embed"
	"io/fs"

	"github.com/hooto/httpsrv/v2"
)

//go:embed views
var views embed.FS

func main() {
	i := httpsrv.NewI18n("en")
	i.Add("en", map[string]string{"welcome": "Welcome"})
	i.Add("zh", map[string]string{"welcome": "欢迎"})

	sub, _ := fs.Sub(views, "views")
	r, err := httpsrv.TemplatesFS(sub, i.Funcs())
	if err != nil {
		panic(err)
	}

	app := httpsrv.New(httpsrv.WithViews(r), httpsrv.WithI18n(i))
	app.Use(httpsrv.AcceptLanguage("en", "zh")) // 探测 locale

	app.Get("/", func(c httpsrv.Ctx) error {
		return c.Render("home.html", map[string]any{"Lang": c.Locale()})
	})

	_ = app.Run(":8080")
}
```

`home.html`：`<h1>{{T .Lang "welcome"}}</h1>`
